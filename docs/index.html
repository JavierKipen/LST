LST — Local Speech Transcriber

Offline Swedish speech-to-text transcription for interviews. No cloud upload.

Why LST

  • Fully offline processing (suitable for sensitive interviews)
  • Optimized for Swedish long-form recordings
  • Simple Windows GUI: pick file → pick quality → transcribe
  • Exports plain text with timestamps
